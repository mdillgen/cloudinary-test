# Defer Tailwind CSS v4

Tailwind will be bumped to the latest 3.x patch as part of the Next.js 16 upgrade, but Tailwind 4 migration is explicitly out of scope for this initiative. Tailwind 4 requires its own config and PostCSS migration; this app uses minimal utilities and Next 16 does not require Tailwind 4.

**Considered options**: Include Tailwind 4 in the same upgrade; freeze Tailwind at the current version.
